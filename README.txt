REACT PRODUCT DEMO - Mobile Web App Development (CP50093E)

HOW TO RUN IT ON YOUR LAPTOP

1. Install Node.js (only once): https://nodejs.org  -> Windows Installer (.msi)
2. Unzip this folder.
3. Open the folder in VS Code:  File -> Open Folder -> react-product-demo
4. Open the terminal:  Terminal -> New Terminal
5. Type these two commands (one at a time):

   npm install
   npm run dev

6. Ctrl + click the link that appears (http://localhost:5173)

WHERE IS THE CODE?
   src/App.jsx   <- all the examples are in this one file

WHAT IS IN THE DEMO?
   Part 1 - Product:       props only (data comes in and is shown)
   Part 2 - ProductCard:   props + state (click Red / Blue)
   Part 3 - ProductPanel:  input boxes + state + Show / Clear buttons

TO STOP THE APP:  click in the terminal and press Ctrl + C
